# MW Voice

AI voice agent for service contractors.
MW Development product — active sales, commission-based partners.

## What it does
Answers inbound calls for contractors (plumbers, roofers, painters, etc.).
Qualifies leads, books appointments, follows up via SMS/email.

## Status
In active sales. Build not started.

## Architecture (planned)
- Voice runtime: ElevenLabs / Vapi
- Logic: FastAPI backend
- CRM integration: per-contractor
- Deployment: SaaS hosted by MW (contractor gets a phone number)
